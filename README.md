## 🔥 Overview

Magma Core Button turns a conventional call-to-action into an interactive volcanic material. Organic procedural noise creates molten lava, cooler crust, illuminated cracks, glossy reflections, and responsive heat distortion. Move your cursor to heat and displace the surface, then press to unleash an eruption of glowing embers.

Created by **Karim Saif** for bold digital experiences.

## ⚙️ Customization

**Content & layout:** Button label, font styling, text color, button height, horizontal padding, corner radius, and section background.

**Magma material:** Lava intensity, scale, animation speed, flow, crust thickness, crust roughness, crack density, crack width, crack glow, core brightness, heat glow, heat distortion, surface gloss, and shadow intensity.

**Interactions:** Cursor reaction on/off, cursor radius, cursor heat, cursor flow, click eruption on/off, eruption strength, eruption duration, and press scale.

**Particles:** Toggle ember particles and fine-tune particle count and size.

**Playback & rendering:** Autoplay, pause motion, and Low / Medium / High quality modes.

## 🚀 Use in Framer

1. Open a Framer project.
2. Create a new Code Component in the **Assets → Code** section.
3. Paste the source from `MagmaCoreButton.tsx` into the component editor.
4. Place the component on your canvas and resize its frame.
5. Customize the available property controls in Framer's right panel.
6. Connect **On Click** to your preferred navigation or action.

The component uses Framer's `addPropertyControls` and `useIsStaticRenderer` APIs. No external animation library is needed.

## ⚡ Performance & accessibility

The implementation uses Canvas 2D sampling with adjustable quality, caps pixel density, reuses texture memory, pauses when the component is outside the viewport or the document is hidden, and respects reduced-motion preferences. The interaction surface is a semantic HTML button with keyboard support. Performance varies with device capabilities and the size of the rendered component.
